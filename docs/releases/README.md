# Releases

Este diretório preserva a documentação histórica dos releases do IronCore Frontend.

Cada release possui seu próprio `README.md` para facilitar navegação direta pelo GitHub e evitar sobrescrita de documentação histórica.

## Índice

| Release | Documento | Status |
| --- | --- | --- |
| `v0.2.0` | [Autenticação, sessão e conta](./v0.2.0/README.md) | Documentação preparada |
| `v0.1.0` | [Foundation técnica e visual do frontend](./v0.1.0/README.md) | Histórico |

## Regra de Manutenção

- Não sobrescrever a documentação de uma release anterior.
- Criar uma nova pasta por release somente depois de haver fechamento público ou técnico relevante.
- Manter o README principal do projeto como visão geral; detalhes técnicos devem ficar nos documentos de release ou nos módulos dentro de `docs/`.
- Milestones do GitHub podem ter numeração própria e representar entregas menores. A release documentada pode consolidar um ou mais milestones.
- A preparação da documentação de uma release não implica publicação de GitHub Release, criação de tag ou disponibilização de artefatos.
